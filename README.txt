WAYORA — Travel Different. Discover More.

PROJECT
WAYORA is a responsive travel and bus-ticket website built with HTML5 and CSS3.

PROJECT FILES
- index.html: website structure, content and page sections
- style.css: design system, Flexbox layouts, responsive styles and animations

FEATURES
- Responsive desktop, tablet and mobile layouts
- Navigation menu for mobile screens
- Bus booking form with built-in validation
- Destination gallery and popular routes
- Travel offers, benefits and experience sections
- Testimonials and newsletter interface
- Hover effects and smooth page transitions

HOW TO RUN
1. Open the project folder in Visual Studio Code.
2. Open index.html.
3. Use Live Server or open the file directly in a web browser.

PROJECT NOTES
- The bus form displays a front-end interface and is not connected to live ticket services.
- Newsletter validation is handled by the browser and is not connected to a mailing service.
- External fonts, icons and photography require an internet connection.
